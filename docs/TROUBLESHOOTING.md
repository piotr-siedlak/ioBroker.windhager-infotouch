# Troubleshooting

| Symptom                                                            | Likely cause                                                                                                   | Action                                                                                                 |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `Authentication failed` and polling stops                          | wrong user/password                                                                                            | fix credentials, restart the instance. Retried automatically only after a restart, to avoid a lock-out |
| `unsupported` / `does not look like a supported InfoWIN REST API`  | other firmware (e.g. a "comWinStack" landing page), wrong host or port, HTTPS-only device                      | open `http://<host>/` in a browser; export diagnostics and open an issue                               |
| `timeout` repeatedly                                               | network, VLAN/firewall, overloaded controller                                                                  | ping the host, raise timeout, set parallel requests to 1, lengthen intervals                           |
| States stay `null`                                                 | placeholder values (`-`), sensor not connected                                                                 | compare with the controller display                                                                    |
| `info.connection` flaps                                            | intervals too aggressive, weak LAN (PowerLAN)                                                                  | lengthen intervals, check `diagnostics.avgLatencyMs`                                                   |
| Structure missing a module                                         | module excluded, function `locked`, request failed                                                             | check the log at debug level, press `diagnostics.rescan`                                               |
| Groups with more than 10 entries incomplete                        | paging contract unverified                                                                                     | experimental; compare counts in `diagnostics.datapoints` against the controller and report             |
| Write refused                                                      | see log code: `disabled`, `not-allowlisted`, `not-writable`, `invalid`, `rejected`, `unverified`, `mismatch`   | each code names the failed check                                                                       |
| Write `mismatch`                                                   | controller clamps or ignores the value                                                                         | adjust to the controller's accepted range; do not retry blindly                                        |
| `Cannot install ...: 0` (exit code 25) when installing from GitHub | package name did not match the repo name (fixed in 0.1.2; older commits were packaged as `iobroker.windhager`) | install 0.1.2 or newer; remove leftovers with `npm uninstall iobroker.windhager` in `/opt/iobroker`    |

Set the instance log level to `debug` to see skipped groups. Credentials and auth headers are never logged. Attach
the anonymised export from the Diagnostics tab to any issue.
