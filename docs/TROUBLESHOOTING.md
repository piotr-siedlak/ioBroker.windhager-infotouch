# Troubleshooting

| Symptom                                                            | Likely cause                                                                                                                                                  | Action                                                                                                                         |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `Authentication failed` and polling stops                          | wrong user/password                                                                                                                                           | fix credentials, restart the instance. Never retried automatically, to avoid a lock-out                                        |
| `unsupported` / `does not look like a supported InfoWIN REST API`  | other firmware (e.g. a "comWinStack" landing page), wrong host or port, HTTPS-only device                                                                     | open `http://<host>/` in a browser; export diagnostics and open an issue                                                       |
| `timeout` repeatedly                                               | network, VLAN/firewall, overloaded controller                                                                                                                 | ping the host, raise the timeout, set parallel requests to 1, lengthen intervals                                               |
| "No route to host" from a Mac                                      | macOS "Local Network" privacy blocks the app                                                                                                                  | System Settings -> Privacy & Security -> Local Network                                                                         |
| States named like `Boiler temperature (00-000)` or only `02-002`   | the controller has no text for that variable in any language                                                                                                  | expected for a few values; the code is the controller's own identifier. Press `diagnostics.rescan` after changing the language |
| All names are codes (`03-051`)                                     | text tables missing/unreadable (log: `Controller text tables not available`)                                                                                  | check `http://<host>/res/xml/VarIdentTexte_en.xml` (needs login); rescan                                                       |
| Names in the wrong language                                        | language setting; the controller offers only de/en/fr/it on the reference firmware                                                                            | set "Language of names"; Polish falls back to English; rescan                                                                  |
| Some states stay `null`                                            | sensor not connected (`-.-`) or no value (`-`)                                                                                                                | compare with the controller display                                                                                            |
| Outside temperature is 0.0 °C                                      | observed on the reference installation (state `00-000` of module UMUMLZ); cause not established - possibly no outdoor sensor or no LON source for that module | compare with the controller display; check which module the outdoor sensor is wired to                                         |
| Time program state is empty                                        | the controller answers HTTP 409 for some time programs (seen for the DHW program `05-061` on the reference controller); the reason is not known               | those programs are skipped; the others are published                                                                           |
| `info.connection` flaps                                            | intervals too aggressive, weak LAN (PowerLAN)                                                                                                                 | lengthen intervals, check `diagnostics.avgLatencyMs`                                                                           |
| Structure missing a module or function                             | module excluded, function `locked` (on the reference controller: `UM (2)`), or a request failed                                                               | check the log at debug level, press `diagnostics.rescan`                                                                       |
| Old `grp_*` states after updating from 0.2.x                       | ids changed in 0.3.0                                                                                                                                          | delete them in the Objects tab; repoint scripts to `modules.node_<n>.fn_<f>.<GG-MMM>`                                          |
| Groups with more than 10 entries incomplete                        | paging (experimental) failed on other firmware                                                                                                                | compare `diagnostics.datapoints` with the controller and report; not needed on MB6621 0.10.4                                   |
| Write refused                                                      | see the log code: `disabled`, `not-allowlisted`, `not-writable`, `invalid`, `rejected`, `unverified`, `mismatch`                                              | each code names the failed check                                                                                               |
| Write `mismatch`                                                   | the controller clamps, delays (> 3 s) or ignores the value                                                                                                    | use a value inside the reported range; do not retry blindly                                                                    |
| `Cannot install ...: 0` (exit code 25) when installing from GitHub | package name did not match the repository name (before 0.1.2)                                                                                                 | install a current version; remove leftovers with `npm uninstall iobroker.windhager` in `/opt/iobroker`                         |

Set the instance log level to `debug` to see skipped groups and text-table loading. Credentials and authentication
headers are never logged. Attach the anonymised export from the Diagnostics tab to any issue.
